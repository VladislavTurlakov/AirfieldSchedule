Проект был реализован на первом курсе университета в 2022 году.

Описание проекта:
Программа предназначена для чтения и обработки данных о рейсах из текстового файла InfoSchedule.txt.
Она выполняет проверку корректности введённых данных, сортирует рейсы по времени посадки и выводит их в виде отформатированной таблицы, сгруппированной по аэродрому посадки.

Функциональность:
1. Проверяет наличие и корректность файла InfoSchedule.txt;
2. Считывает данные о каждом рейсе (время посадки, модель самолёта, номер, аэродром);
3. Проверяет формат введённых данных на ошибки;
4. Сортирует рейсы по времени посадки (по убыванию);
5. Выводит таблицу с результатами, разделяя рейсы по номерам аэродромов (АП1, АП2, АП3).

Пример входных данных:
Файл InfoSchedule.txt должен содержать данные в следующем формате (одна строка — один рейс)
 hh:mm МС-123 Б-0001 АП1
 hh:mm АН-225 Б-5678 АП2
 hh:mm ТУ-204 Б-9876 АП3

Где:
1. hh:mm — время посадки (00:00–23:59),
2. МС-123 — марка самолёта (допустимый формат XX-123, где X — кириллические буквы),
3. Б-0001 — бортовой номер,
4. АП1 — номер аэродрома (АП1, АП2, АП3)

Структура программы:
1. Data — хранит данные одного рейса.
2. Index — используется для сортировки по времени.
3. ReadFile() — проверяет файл, выводит содержимое, считает количество строк.
4. ReadTable() — считывает и валидирует данные.
5. Sort() — сортирует записи по времени посадки.
6. PrintTable() — выводит отформатированную таблицу.
